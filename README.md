# DayFlow

HR management system built for a hackathon: attendance, leave, payroll, and workforce analytics with an AI HR Copilot.

## Team

| Member | Area |
|---|---|
| Saksham | Frontend |
| Santhosh | Frontend |
| Hamza | Backend |

## Structure

- `frontend/` - React + Vite app (Saksham, Santhosh)
- `backend/` - Node.js/Express API (Hamza)
- `database/` - schema and sample data
- `docs/` - architecture, API, features, demo flow
- `tests/` - backend and frontend tests

## Getting started

```bash
npm run setup        # installs frontend + backend dependencies
cp .env.example backend/.env
```
